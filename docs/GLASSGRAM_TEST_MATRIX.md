# Glassgram test matrix

Этот документ планирует проверки; тесты не запускались. Первый gate — неизменённый official baseline build, затем по одной поверхности за раз.

| Область | Сценарии | Условия / критерий |
|---|---|---|
| Визуальный baseline | список, выбранный чат, header, пузырь, composer, popup, settings, Classic | 1280×720, 1440×900, 1920×1080; сравнить скриншоты с baseline |
| DPI и текст | RU/EN, длинные имена, переносы, emoji, RTL, timestamps, unread, disabled | 100/125/150/200%; нет обрезки и снижения читаемости |
| Glass POC | scroll, resize, moving media, screen/window state | только in-app backdrop; opaque fallback корректен; blur не оставляет stale pixels |
| Производительность | idle, прокрутка, 100 переключений, большая история, media-heavy chat, minimize/restore | одна машина и одинаковый build; CPU/GPU, frame-time p50/p95/p99, dropped frames; цель 60 FPS при 60 Hz, без заметного регулярного jank |
| Переход чата | мышь/клавиатура, быстрые повторные переключения, поиск/back, minimize | отмена предыдущего перехода, нет чужого stale content, навигация сразу корректна |
| Отправка текста | короткое/длинное/многострочное, повторная отправка, задержка/ошибка сети, scroll | анимация визуальная, без дублей/задержки ввода/влияния на порядок и delivery state |
| Режимы | toggle Glass/Classic, restart, theme change, reduced motion | настройки локальны, переживают перезапуск, Classic faithful, motion отключается |
| Функциональная регрессия | login/logout, диалоги, группы/каналы, поиск, вложения, вызовы, уведомления, shortcuts | не менять протокол, read receipts, retention и семантику аккаунта |
| Изоляция | параллельный старт, данные, lock/mutex, ярлыки, уведомления, протокол, автозапуск, updater | идентификаторы и пути независимы; пустой отдельный профиль; не проверять реальным аккаунтом до gate |
| Надёжность / упаковка | офлайн, suspend/resume, resize во время анимации, DPI switch, upgrade/rollback | нет зависания/потери настроек; updater проверяет подпись/целостность |

Для каждого будущего изменения фиксировать commit, конфигурацию, точные команды, коды возврата, артефакты, видео/скриншоты и известные ограничения. Матрица основана на [GLASSGRAM_PLAN.md](../GLASSGRAM_PLAN.md); фактическое исполнение отмечать отдельно.

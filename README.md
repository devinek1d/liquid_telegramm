# Glassgram — аудит и подготовка

Этот репозиторий — стартовый audit repo для проверки реализуемости Glassgram и фиксации требований. Это **не готовый форк Telegram Desktop, не собранное приложение и не распространяемый бинарник**. Исходники Telegram Desktop подключаются отдельно как Git submodule в `upstream/` и закрепляются на проверенной ревизии `7381fb1df75d863eb3463fdddef57a2ac51f1d56`.

Glassgram задуман как отдельный сторонний клиент для Windows. Он не является официальным приложением Telegram. До выполнения Stage 0 нельзя начинать редизайн: сначала нужно добиться воспроизводимой сборки неизменённой upstream-версии и подтвердить независимость идентичности и локальных данных.

## Получение репозитория

После публикации audit repo склонируйте его вместе с submodule:

```powershell
git clone --recurse-submodules https://github.com/devinek1d/liquid_telegramm.git
cd liquid_telegramm
git submodule status
```

Если репозиторий уже склонирован без submodule:

```powershell
git submodule update --init --recursive
```

Проверьте, что `git submodule status` показывает для `upstream` ревизию `7381fb1df75d863eb3463fdddef57a2ac51f1d56`. В самом репозитории `upstream/` содержит исходный проект Telegram Desktop; изменения продукта Glassgram следует вести отдельно, не выдавая исходный upstream за собственную реализацию.

## Текущий блокер сборки

На момент аудита не обнаружены Visual Studio/MSVC, Windows SDK, CMake и Qt; найдены Git 2.56.0 и Python 3.12.10 x64. План ожидает Python 3.10. На системном диске C: было 42,4 ГиБ свободно. Поэтому сборка пока не запускалась. Подробности, точные команды и ограничения проверки — в отчёте среды. Не устанавливайте зависимости автоматически: сначала сверяйтесь с актуальными инструкциями upstream и используйте согласованный способ подготовки среды.

## Переход к полноценному форку

Этот audit repo хранит требования и результаты проверки, а upstream остаётся отдельной историей в submodule. Если проект перейдёт к полноценному форку, создайте отдельный canonical репозиторий Glassgram на базе Telegram Desktop с upstream-коммитом `7381fb1df75d863eb3463fdddef57a2ac51f1d56` в его настоящей Git-истории. Перенесите сюда созданные документы отдельным коммитом или сохраните audit repo как архив/сопутствующий репозиторий. Не копируйте исходники в новый репозиторий как единственный начальный snapshot и не переписывайте историю Telegram Desktop: так история upstream останется доступна через предков форка. Перед переключением обновите ссылки на документы и закреплённую ревизию, а submodule удаляйте только из нового canonical репозитория, когда его собственная история уже содержит исходный код.

Никаких UI-изменений или данных пользовательского Telegram-профиля в рамках этого стартового репозитория нет.
